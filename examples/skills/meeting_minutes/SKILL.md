# 会议纪要与行动项

## 触发条件

当用户要求整理会议纪要、提取决策、负责人、截止时间或行动项时使用。

## 执行流程

1. 区分参会人、议题、事实、讨论意见和最终决策。
2. 提取行动项，包含负责人、截止时间、优先级；缺失信息标注“待确认”，不得臆造。
3. 输出会议摘要、决策清单、行动项表格和风险提醒。
4. 用户要求文档时调用 `report.generate_document` 输出 DOCX 或 PDF。

## 质量要求

- 不把讨论意见误写成最终决定。
- 所有日期使用明确格式。
- 对缺失负责人或期限的行动项给出待确认标记。
