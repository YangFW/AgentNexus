# 通用任务处理 Skill

## 使用条件

当用户提出的任务没有明确匹配到专项 Skill，或者只是需要整理思路、生成计划、输出总结时，使用本 Skill。

## 执行原则

1. 先理解用户目标，不要急着调用工具。
2. 任务需要多个步骤时生成执行计划；简单问题直接回答。
3. 如果平台中存在更合适的专项 Skill，应优先切换到专项 Skill。
4. 如果需要外部系统能力，应检查是否有可用 MCP。
5. 最终输出只保留完成当前目标所需的结论、依据和交付内容。

## 输出格式

遵循用户指定的格式。用户没有指定时，先给出结论，再补充必要说明；不要固定套用“任务理解”“执行过程”或 Skill 推荐模板。
